# Changesets

This directory holds [changesets](https://github.com/changesets/changesets) — one Markdown file per
unreleased change. Run `npm run changeset` to add one, `npm run version-packages` to apply pending
changesets to package versions, and `npm run release` to publish.

`estreuv-playground` is ignored (it is an in-repo demo/test app, never published).
