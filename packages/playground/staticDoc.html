EstreUV.js integration test

EstreUI v1.4.0 article 안에 EstreUV (Lit micro-Rimwork) tile 삽입. npm create estreui 스캐폴드 + npm install estreuv 흐름의 실 사용자 시나리오. 검증: lifecycle 자동 dispatch · intent 재렌더 · dual binding 회피 · Alienese alias · lifecycle race dedup.

EstreUV tiles (3종 — reactivity 패턴 일반화 검증)

Notelle 사이드바 prototype (nested 컨테이너 + 중첩 lifecycle)

사이드바 (data-estreuv) + 항목들 (data-estreuv, slot 의 light-DOM 자식) 모두 article 의 flat dispatch (querySelectorAll('[data-estreuv]')) 로 lifecycle 받음. 헤더 클릭 → collapsed 토글 (항목들에 prop-down). 항목 클릭 → active (event-up).

검증 콘솔 가이드 (DevTools)

// (1) F1 — article lifecycle 자동 전파: 부트 시 [estreuv-app] HomePageHandler.onBring/onOpen/onShow 로그 + tile 의 onShow 호출

// (2) intent 변경 시 tile reactive property 갱신
window._spikeIntent.update({ darkMode: "dark" });

// (3) child → article event-up (dual binding 회피)
document.querySelector('estreuv-dark-mode-tile').cycle();
//     → [estreuv-app] intent-update via event: { darkMode: ... }

// (4) F3 — Alienese alias JS 식별자 (long-form 과 같은 reactive prop)
const $tile = document.querySelectorAll('estreuv-dark-mode-tile')[1];
$tile['*t'] = 'AI 테마';    // long-form text 동일 — 라벨 즉시 갱신
$tile['*c'] = 'tomato';     // long-form color 동일 — 색 즉시 갱신

// (5) lifecycle race 정밀 — 같은 tick 동기 두 번 호출 시 dedup
window._spikeLifecycle.onShow({stub:true}); window._spikeLifecycle.onShow({stub:true});
//     → 두번째가 "[EstreUV] dispatchLifecycle('onShow') re-entrant ... skipped" 경고, counter +1만

// (6) lifecycle 카운터 + history
const $any = document.querySelector('estreuv-dark-mode-tile');
$any._estreuvLifecycleCounts;     // 각 hook 호출 횟수
$any.getLifecycleHistory();       // 시간순 이력 (bounded 32)
$any.hasLifecycleFired('onShow'); // boolean

// ─── Phase C tiles ───────────────────────────────────────
// (7) clock-tile — timer 가 lifecycle 로 제어되는지: onHide 시 정지, onShow 시 재시작
const $clock = document.querySelector('estreuv-clock-tile');
$clock.onHide();        // → data-running 사라지고 시각 흐림 (타이머 정지)
$clock.onShow();        // → 다시 live (타이머 재시작) — setInterval 누적 없음
$clock['*fmt'] = '12h'; // → 12시간제로 즉시 전환 (Alienese alias)

// (8) notif-count-tile — external-driven count + intent 위임 (dual binding 회피)
const $notif = document.querySelector('estreuv-notif-count-tile');
$notif.bump();          // → 배지 +1, 콘솔에 "[estreuv-app] intent-update via event: { notifCount: ... }"
$notif['*c'] = 5;       // → 배지 5 (Alienese alias *c → count)
$notif.clear();         // → 배지 사라짐 + intent 0 위임
// onShow 시 intent.notifCount 동기 검증:
window._spikeIntent.update({ notifCount: 42 }); $notif.onShow();  // → 배지 42
