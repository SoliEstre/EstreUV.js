EstreUV-spike — bridge scenario

EstreUI article 환경 가정. EstreUI 미로드 시에는 stub lifecycle 자동 트리거.

이 영역은 [data-spike-article] = stub article. 실 EstreUI 가 있으면 이 root 가 EstreUI 의 article 로 교체되고, intent provider 가 그 article 에 바인딩됩니다.

DevTools 콘솔에서:

_spikeIntent.update({ flags: { highlighted: true } })
_spikeLifecycle.onFocus({ stub: true }, true)  // isFirstFocus=true
_spikeLifecycle.onHide({ stub: true })
