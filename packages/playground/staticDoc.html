EstreUV.js — 강결합 페어 데모

EstreUI v1.4.0 article 안 EstreUV(Lit micro-Rimwork) 컴포넌트들이 단일 공유 intent ({ sidebarActive, counts, notifCount, darkMode }) 를 공유 — 무엇을 클릭하든 event-up → intent → prop-down 으로 여러 영역이 동시에 반응한다. 실사용 시나리오: 알림·인박스 패널. npm create estreuv -- --pair 흐름의 결과물.

Messages

강결합 루프

폴더 클릭 → sidebarActive 변경 → 메시지 리스트 전환 + active 하이라이트. 메시지 읽음 → counts 재계산 → 사이드바 배지 + 상단 unread 동시 갱신 (단일 소스). 8초마다 수신 시뮬 → Inbox 배지 증가. dark-mode → 패널 테마. 모든 연결이 requestIntentUpdate() (event-up) → intent → 자동 재렌더 (prop-down).

검증 콘솔 가이드 (DevTools)

// 강결합 루프 — UI 로 직접 해보거나 콘솔로 확인.

// (A) 폴더 전환 (event-up → intent.sidebarActive → 메시지 리스트 prop-down)
//     사이드바 'Archive' 클릭 → 리스트가 Archive 메시지로 전환 + active 하이라이트
//     또는 콘솔: window._spikeIntent.update({ sidebarActive: 'Archive' });

// (B) 메시지 읽음 → counts 재계산 → 사이드바 배지 + 상단 unread 동시 갱신 (단일 소스)
document.querySelector('estreuv-message-list')._read(
  document.querySelector('estreuv-message-list')._messages.find(m => !m.read));
//     → Inbox 배지 -1, 상단 🔔 unread -1 동시. [estreuv-app] intent-update via event: { counts, notifCount }

// (C) 수신 시뮬 (external-driven) — Inbox 에 새 메시지 + 배지 증가 (8초마다 자동도)
document.querySelector('estreuv-message-list').simulateIncoming();

// (D) F3 — Alienese alias (long-form 과 같은 reactive prop, build 0)
const $tile = document.querySelector('estreuv-dark-mode-tile');
$tile['*t'] = 'AI theme';   // = $tile.text — 라벨 즉시 갱신
$tile.cycle();              // 테마 토글 → intent.darkMode (event-up)

// (E) lifecycle race dedup — 같은 tick 두 번 호출 시 2번째 skip
window._spikeLifecycle.onShow({stub:true}); window._spikeLifecycle.onShow({stub:true});
//     → "[EstreUV] dispatchLifecycle('onShow') re-entrant ... skipped" 경고, counter +1만

// (F) lifecycle 카운터 / history
const $any = document.querySelector('estreuv-sidebar');
